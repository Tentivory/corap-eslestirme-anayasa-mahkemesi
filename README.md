# Çorap Eşleştirme Anayasa Mahkemesi

> Resmi slogan: *Tek kalan çorap masumdur, ta ki çamaşır makinesi aksini ispatlayana kadar.*

Bu depo, insanlığın çözemediği tek gerçek krizi ele alır: çekmeceden çıkan tek çorap. Diğer çorap kaybolmamıştır. Diğer çorap **yetki alanı dışına** çıkmıştır. Bu ayrım önemlidir. Birincisi ev işidir, ikincisi yüksek yargı işidir.

## Neden var?

Çünkü bir çorabın eşi olmadan giyilmesi, kişinin ayak başına eşitlik ilkesini ihlal eder. Sol ayak ile sağ ayak arasında renk, desen ve delik sayısı bakımından makul denge kurulmadan evden çıkılamaz. Bu yazılım, o dengeyi **bağlayıcı olmayan** bir karar ile tesis eder.

Bağlayıcı olmaması kasıtlıdır. Mahkeme, çorapların infazını çamaşır sepetine bırakmıştır.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Bağımlılık olsaydı çoraplar gibi kaybolurdu.

```bash
python corap_mahkemesi.py
```

İnteraktif duruşma:

```bash
python corap_mahkemesi.py --dava "lacivert noktali, topukta mini krater"
```

JSON gerekçeli karar (arsiv icin, cunku tarih affetmez, çekmece de affetmez):

```bash
python corap_mahkemesi.py --json
```

## Yargılama usulü

1. Çorap kimlik tespiti yapılır. Çorap konuşamaz. Bu, susma hakkı değil, iplik olmasıdır.
2. Eş adayları "makul şüphe" ve "aynı çamaşır günü" kriterleriyle elenir.
3. Karşı oy gerekçesi yazılır. Karşı oy her zaman vardır. Karşı oy, tek çorabın ta kendisidir.
4. Karar açıklanır. Uygulanması kullanıcının ayaklarına kalmıştır.
